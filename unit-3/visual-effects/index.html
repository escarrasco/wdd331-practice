Blend Modes & Shape-Outside

The circular image uses shape-outside: circle(50%) so the paragraph text wraps its curved edge. A mix-blend-mode: multiply overlay tints the photo with the accent colour; hover to reveal the original. The colour-wash strip below demonstrates mix-blend-mode: soft-light.

When shape-outside is applied to a floated element, the browser calculates the inline flow of surrounding text around the geometric shape rather than the element's rectangular bounding box. Here the float is a perfect circle, so the paragraphs hug its curved edge naturally.

The accent-coloured overlay uses mix-blend-mode: multiply, which darkens where the overlay and the image overlap — deep shadows in the photo become richer, while highlights retain brightness. Hover over the circle to toggle the overlay off and see the original image underneath.

Blend modes work best when paired with semi-transparent colours. The opacity: 0.45 on the overlay keeps the tint subtle enough that the photo remains legible while the colour theme still comes through. In dark mode the same rule applies because the overlay is driven by var(--color-accent), which already adapts via light-dark().
